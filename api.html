Developer API Portal

Mfumo rasmi wa ushirikiano wa kiteknolojia — unganisha mifumo yako na huduma za UNP TOURS kwa usalama.

Kuhusu API Yetu

UNP TOURS inatoa huduma salama za RESTful API kwa taasisi, washirika, na watengenezaji programu (developers) wanaotaka kuunganisha mifumo yao moja kwa moja kwa ajili ya upatikanaji wa taarifa za safari, uhifadhi, na huduma za kitamaduni.

Vitu Unavyoweza Kufanya Kwenye Mfumo

  • Kuchukua orodha na taarifa za kina za safari zote zilizopo.
  • Kuchukua taarifa za trip moja maalum kupitia kitambulisho chake (trip_id).
  • Kutafuta na kuchuja trips kwa kategoria au eneo husika.
  • Kusajili na kuweka booking mpya moja kwa moja kupitia mfumo wako.
  • Kukagua hali ya bookings za wateja na mapitio (reviews).

Taratibu za Kuanza (Getting Started)

1. Sajili Akaunti ya Partner/Developer

Wasiliana nasi kupitia barua pepe au WhatsApp ili kusajiliwa kama mshirika rasmi wa kiteknolojia.

2. Pokea API Key Yako Maalum

Baada ya uhakiki, utapewa ufunguo wa siri wa API (Bearer Token) utakaouweka kwenye vichwa vya maombi yako (Headers).

3. Anza Kufanya Muunganisho

Tumia nyaraka zetu hapa chini kujaribu maombi kwenye mifumo yako ya majaribio (Sandbox).

Mifano ya Maombi (API Endpoints)

Kumbuka: Hizi ni mifano ya jinsi API itakavyofanya kazi. Endpoints za kweli zitafunguliwa hivi karibuni.

1. Kuchukua Trips Zote:

GET https://api.unp.tours/v1/trips
Headers: { "Authorization": "Bearer YOUR_API_KEY" }

2. Kuchukua Trip Moja kwa ID:

GET https://api.unp.tours/v1/trips/{trip_id}
Headers: { "Authorization": "Bearer YOUR_API_KEY" }

3. Kutafuta Trips kwa Kategoria:

GET https://api.unp.tours/v1/trips/search?category=Zanzibar&limit=10
Headers: { "Authorization": "Bearer YOUR_API_KEY" }

4. Kuweka Booking Mpya:

POST https://api.unp.tours/v1/bookings
Headers: {
  "Authorization": "Bearer YOUR_API_KEY",
  "Content-Type": "application/json"
}
Body: {
  "trip_id": "trip_123",
  "name": "John Doe",
  "email": "john@example.com",
  "date": "2026-12-15",
  "guests": 2
}

Viwango vya Matumizi (Rate Limits)

  • Free Tier: 100 requests / siku (Kwa ajili ya majaribio pekee)
  • Basic Partner: 1,000 requests / siku
  • Pro Partner: 10,000 requests / siku
  • Enterprise: Huduma maalum isiyo na kikomo
